# Diogenes documentation source

This directory contains the F#-wrapped source for `dio.shel.sh`. Preview renders
the wrappers into Markdown, JavaScript, CSS, templates, and `zensical.toml` in a
temporary output directory.

## Run Preview

Open the Preview GUI and select this directory, or start it from PowerShell:

```powershell
$preview = 'C:\Users\turtleuser\Documents\Dev\Website Stuff\preview\target\release\orc-preview.exe'
$site = 'C:\Users\turtleuser\Documents\Dev\Website Stuff\orc\orc\dio'
$runtime = 'C:\Users\turtleuser\Documents\Dev\Website Stuff\orc\orc\GenerateConfig.fsx'
& $preview --single-dir=$site --runtime-dir=$runtime --ports 4003
```

Restart the site after changing `zensical.fs`, an override, or navigation.
Content and asset wrappers are re-rendered by the normal Preview cycle.

## Add pages

Create a `sharpmd-<name>.fs` wrapper beneath `docs/<section>/`. A section landing
page uses `indexmd.fs` and renders to `index.md`.

For a batch of Markdown files, use the generator:

```powershell
$orc = 'C:\Users\turtleuser\Documents\Dev\Website Stuff\orc\orc'
dotnet run --project "$orc\src\generator\Generator.fsproj" -- wrap-batch '<input-directory>' "$PWD\docs"
```

Add each rendered path to the navigation array in `zensical.fs`.

## Verify

1. Restart Preview after configuration or navigation edits.
2. Check the desktop and narrow-width layouts at `http://localhost:4003`.
3. Open a page with Mermaid, a code block, tabs, and math.
4. Run the navigation audit generated by `sharppy-sync_nav.fs`.
5. Run the banned-vocabulary and broken-link checks recorded in
   `IMPLEMENTATION-TODO.md`.
6. Keep rendered output outside this source directory.
